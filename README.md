# 🛒 PHP & MySQL E-Ticaret Altyapısı (WIP)

Bu proje, temel e-ticaret süreçlerini (ürün listeleme, sepet yönetimi, kullanıcı doğrulama) yönetmek amacıyla **PHP ve MySQL** kullanılarak sıfırdan geliştirilmektedir. Proje şu an aktif olarak geliştirme aşamasında olup, yeni modüller eklenmeye devam etmektedir.

### 🚧 Proje Durumu: Geliştirme Aşamasında (Work in Progress)
Mevcut kod tabanı, temel veritabanı işlemlerini (CRUD) ve dinamik içerik yönetimini içermektedir.

### 🛠️ Kullanılan Teknolojiler
* **Back-End:** PHP (Oturum yönetimi, veri işleme, yönlendirmeler)
* **Veritabanı:** MySQL (İlişkisel veritabanı tasarımı, güvenli sorgular)
* **Front-End:** HTML5, CSS3, Bootstrap (Kullanıcı ve Admin paneli arayüzleri)

### ⚙️ Mevcut ve Planlanan Özellikler
- [x] Dinamik ürün listeleme ve kategori yapısı
- [x] Veritabanı (SQL) bağlantıları ve mimarisinin kurulması
- [x] Admin paneli üzerinden ürün Ekleme/Silme/Güncelleme (CRUD) işlemleri
- [ ] Kullanıcı kayıt, giriş ve oturum (Session) yönetimi *(Geliştiriliyor)*
- [ ] Sepete ürün ekleme ve sipariş tamamlama akışı *(Geliştiriliyor)*

### 💡 Geliştirici Notu
Bu projede hazır bir CMS (WordPress vb.) kullanılmamış olup, tüm arka plan mimarisi, veritabanı tabloları ve admin paneli entegrasyonu manuel olarak kodlanmaktadır.
